# Blinkit-PowerBIDashboard
Blinkit Sales Analysis Dashboard – Power BI
📌 Problem Statement

Blinkit aims to analyze its overall sales performance, customer satisfaction, and inventory distribution to identify key insights and opportunities for optimization. The goal was to visualize sales KPIs and business metrics to support data-driven decisions.
🧠 Objective

To conduct a comprehensive analysis of Blinkit’s data using Power BI, focusing on KPIs such as Total Sales, Average Sales, Number of Items Sold, and Average Ratings.
⚙️ Work Done

Imported and cleaned raw Blinkit dataset in Power BI

Created calculated columns and DAX measures for KPIs

Designed interactive visuals and filters (Outlet Type, Size, Location, and Item Type)

Built dashboard to analyze relationships between fat content, item type, outlet characteristics, and sales performance

📊 Key Insights

Regular fat products contributed to higher total sales compared to low-fat products.

Supermarket Type 3 outlets generated the highest total sales across all categories.

Medium-sized outlets performed best in terms of revenue.

Average customer rating: 3.9 indicates moderate satisfaction, suggesting potential for improvement.

Sales peaked in the year 2018 with $205K total revenue.

🧰 Tools & Technologies

Power BI – Dashboard creation and DAX calculations

Excel – Data cleaning and preparation

Data Modeling – Relationships between fact and dimension tables

📈 Dashboard Overview

KPIs: Total Sales | Average Sales | Number of Items | Average Rating

Visuals Used: Donut Chart, Bar Chart, Line Chart, Stacked Column Chart

Interactive Filters: Outlet Type, Size, Location, and Item Type

🏁 Outcome

Delivered a fully interactive Power BI dashboard that helps Blinkit management monitor performance metrics, identify top-performing categories, and make better inventory and sales decisions.
